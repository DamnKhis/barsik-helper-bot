# Исходные документы базы знаний

Сюда кладём **PDF** от организаторов (критерий №1 хакатона):

- «Функциональные возможности с БАРС-Офисом»
- «БП Командировка»
- «Реестр мебели»

Файлы .pdf/.docx в Git **не коммитятся** (см. .gitignore, NDA) — они нужны
только для индексации: `make index`.

Пайплайн (`indexer/parse_pdf.py`, PyMuPDF):
- заголовки разделов — по нумерации («2.3 Аванс») и размеру шрифта;
- таблицы — одним markdown-блоком (фолбэк на pdfplumber);
- скриншоты интерфейса — сохраняются в `data/screenshots/`, подпись делает
  VLM (задайте `VLM_MODEL` в .env), иначе плейсхолдер — без этого бот не
  ответит на вопросы «как выглядит кнопка»;
- сканированные страницы — OCR (нужен tesseract в системе).
