# Исходные документы базы знаний

Сюда кладём .docx/.md от организаторов (критерий №1 хакатона):

- «Функциональные возможности с БАРС-Офисом»
- «БП Командировка»
- «Реестр мебели»

Файлы .docx/.pdf в Git **не коммитятся** (см. .gitignore, NDA) — они нужны
только для индексации: `make index`.

Скриншоты интерфейса из документов — важный источник: их подписи получает
VLM-модуль (`indexer/parse_docx.py`, TODO роль 1) и кладёт в текст чанка,
иначе бот не ответит на вопросы «как выглядит кнопка».
