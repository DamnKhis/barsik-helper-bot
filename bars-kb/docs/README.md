# Документация

```text
docs/
├── source/    # вход пайплайна: DOCS_PATH=docs/source
│   ├── БП Командировка.pdf
│   ├── Реестр мебели.pdf
│   └── Функциональные_возможности_работы_с_БАРС_Офисом.pdf
└── context/   # материалы задания, в базу знаний НЕ попадают
    ├── Шаблон_Бриф _ хакатон.pdf
    └── Критерии_оценивания_БАРС_Групп_Корпоративный_Telegram_бот.pdf
```

`source/` — единственная папка, которую читает `bars-kb ingest` по умолчанию.
`context/` хранится рядом для истории проекта и не индексируется.

Новые документы кладите в `source/` и запускайте:

```bash
bars-kb sync
```
